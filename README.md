# nasa mission tracker

## Project Idea

NASA Space Mission Planner is a centralized mission hub that helps track space exploration projects from launch to completion. It organizes important mission information such as targets, launch windows, objectives, milestones, and current status in one place.

This can help space agencies and researchers keep track of active and previous missions without having the information spread across different places.

## Technologies and Tools

- HTML
- CSS
- JavaScript
- Git
- GitHub
- Visual Studio Code

## How to Run or Use the Project

1. Clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file.
4. Run it using a web browser.
5. View the available space mission information.
